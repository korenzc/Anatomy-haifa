# Somatomi

אפליקציה לתרגול אנטומיה עיונית לקראת הבחנים: מסלול של שיעורים קצרים לכל הרצאה, מבחנים מסכמים, ותרגול עם אלגוריתם חזרה מרווחת שמחזיר בדיוק את מה שאתם עומדים לשכוח.

**כל החומר לקוח מהמצגות של הקורס, ורק מהן.** כל מצגת היא הרצאה במסלול.

המקצועות: מבואות · גפה עליונה · עמוד שדרה, גב וגולגולת · ראש, פנים וצוואר. מקצוע בלי מצגות לא מוצג עד שעולה אליו ההרצאה הראשונה.

נבנה על בסיס האפליקציה "לדבר רפואית" של איתן.

מפה מלאה של הקוד: [docs/APP-MAP.md](docs/APP-MAP.md).

## מבנה התוכן

```
src/content/
  courses/index.ts            רשימת הקורסים, לפי הסדר באפליקציה
  courses/<course>/index.ts   קורס: id, שם, אייקון, צבע, ורשימת הרצאות
  courses/<course>/NN-*.ts    הרצאה אחת = מצגת אחת
  lexicon.ts                  מונחים וחלקי מילים (רק מה שמופיע באיזו הרצאה)
```

### הוספת מצגת לקורס קיים

יוצרים `src/content/courses/<course>/NN-<name>.ts` ומוסיפים אותו לרשימת `lectures` ב־`index.ts` של הקורס:

```ts
const lecture: Lecture = {
  id: 'cell-membrane',                 // קבוע לתמיד — ההתקדמות של כולם נשמרת לפיו
  added: '2026-11-02',                 // היום שההרצאה עלתה — מופיעה ב"מה חדש" ל־21 יום
  // updated: { date: '2026-11-09', note: 'נוספו 6 שאלות משקפים 12–18' },   // עדכון תוכן מאוחר יותר
  title: 'קרום התא', subtitle: '…', source: 'שם קובץ המצגת', icon: '🧫', hue: 150,
  facts: [
    { id: 'lipid-bilayer', q: 'ממה בנוי קרום התא?', a: 'דו־שכבה של פוספוליפידים', wrong: ['…', '…', '…'], slide: 4 },
  ],
  words: ['hypertension'],            // מונחים מהמצגת (מוגדרים ב־lexicon.ts)
  corrections: [{ slide: 7, says: '…', correct: '…' }],   // טעויות במצגת, אם יש
};
```

- `facts` — שאלה בעברית ותשובה קצרה, בדיוק לפי השקף. `slide` מציג "שקף N", `explain` מוסיף הסבר אחרי התשובה, `img` תמונה מ־`public/`. `wrong` — מסיחים טובים לשאלת הבחירה (אם אין, נלקחות תשובות של שאלות אחרות באותה הרצאה/קורס).
- `words`/`parts` — למונחים: מוסיפים את המונח ל־`lexicon.ts` עם פירוק לחלקים (`parts` חייבים להצטרף בדיוק למילה):
  `{ word: 'pericarditis', parts: ['peri', 'card', 'itis'], he: 'דלקת קרום הלב', en: 'inflammation around the heart', level: 2 }`

### הוספת קורס חדש

תיקייה חדשה `src/content/courses/<id>/` עם `index.ts` שמייצא `Course` (`id`, `title`, `subtitle`, `icon`, `hue`, `lectures`), ומוסיפים אותו ל־`courses/index.ts`. קורס עם `lectures: []` לא מוצג לסטודנטים בכלל, עד שעולה אליו ההרצאה הראשונה. כל עוד יש רק קורס אחד עם חומר, אין באפליקציה שורת מקצועות. מבואות ראשון ברשימה ולכן הוא ברירת המחדל.

אחרי כל שינוי מריצים:

```bash
npm run validate
```

הבודק מוודא שכל מילה מתפרקת נכון, שאין כפילויות, שכל שאלה בעברית ושיש לה תשובה, ש־id של הרצאות ייחודיים, ושאין במילון מונח שאף הרצאה לא מלמדת. ה־build נכשל אם יש שגיאה. ההתקדמות של המשתמשים לא נפגעת מהוספת תוכן.

## פיתוח

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות יחידה (רצות על תוכן בדיקה שלא נכנס לאתר)
npm run build      # בדיקת תוכן + typecheck + build
```

React 19 + TypeScript + Vite, ‏Motion לאנימציות, ‏Vaul ל־bottom sheets, ‏ts-fsrs לחזרה מרווחת. PWA — אפשר להוסיף למסך הבית ולעבוד בלי אינטרנט. ההתקדמות נשמרת מקומית בדפדפן (גיבוי לקובץ במסך "התקדמות").

העיצוב נשען על Apple Human Interface Guidelines (טיפוגרפיה, צבעי מערכת, tab bar, sheets, RTL) ועל עקרונות האנימציה של Emil Kowalski (ease-out, משכים קצרים, משוב לחיצה, בלי אנימציה על פעולות תכופות, כיבוד reduced-motion).
